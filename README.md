# Отчет по проекту: Расширение для браузера с OCR для азербайджанских документов

## Описание задачи

Создание браузерного расширения с функцией OCR для распознавания текста на азербайджанских документах:

* Рукописный текст
* Печатный текст
* Азербайджанская кириллица (старая)

## Выполненные работы

## 1. Установка и настройка окружения

```
git clone https://github.com/reyquazar/image-to-text.git
cd image-to-text
git checkout develop
```

# requirements
```
pip install -r requirements.txt
```

## 2. Разметка данных

* Запущен инструмент разметки: ```python .\PPOCRLabel.py --lang en```
* Размечено 8 изображений
* Расположение данных:
* Изображения: ```./text/typed_text/crop_image```
* Разметка: ```./text/typed_text/rec_gt.txt```

## 3. Подготовка к обучению модели

## Созданные файлы конфигурации:

* ```./text/typed_text/az_rec_config.yaml``` - основной конфиг обучения
* ```./text/typed_text/az_config_train/dict.txt``` - словарь для аугментации данных
* Загружены шрифты для генерации синтетических данных

## Генерация тренировочных данных:

```
python .\genDataTrainVal.py *5000

python .\TrainVal.py
```

## 4. Обучение модели

```
git clone https://github.com/PaddlePaddle/PaddleOCR.git

wget https://paddle-model-ecology.bj.bcebos.com/paddlex/official_pretrained_model/PP-OCRv5_server_rec_pretrained -P ./text/typed_text/pretrain_models

python ../PaddleOCR/tools/train.py -c ./text/typed_text/az_rec_config.yaml
```

* Критерий остановки: достижение accuracy ≥ 90%

## 5. Экспорт модели

```
python ../PaddleOCR/tools/export_model.py -c ./text/typed_text/az_rec_config.yaml -o Global.pretrained_model=output/best_accuracy.pdparams Global.save_inference_dir=output
```

* Важное замечание: Требуется ручное редактирование ```output/inference.yml``` - удаление
  строки ```- CTCLABELENCODE: null```

## 6. Тестирование модели

```
python .\testFast.py .\text\typed_text\textX.png
```

* Тестирование включает сравнение результатов оригинальной и дообученной моделей.

## Проблемы и решения

## Основные сложности:

* Неполная документация PaddleOCR - потребовалось дополнительное время для поиска рабочей конфигурации
* Интеграция PaddleOCR в браузерное расширение - отсутствие готовых решений привело к выбору серверной архитектуры
* Проблемы с экспортом модели - необходимость ручного редактирования конфигурационного файла

## Принятые решения:

* Выбор PaddleOCR вместо TesseractOCR из-за большей мощности
* Реализация серверной архитектуры для обработки изображений
* Создание собственного конвейера генерации синтетических данных
